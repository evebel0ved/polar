# Polaroid Camera Photo Maker

폴라로이드 카메라 컨셉의 사진 메이커 사이트입니다. 사용자가 업로드한 사진을 폴라로이드 카드로 변환하여 PNG 또는 GIF로 저장할 수 있습니다.

## 주요 기능

### 📷 사진 관리
- 사용자 사진 업로드
- 자동 비율 조정
- 사진 위치 및 크기 조절

### 🎨 디자인 커스터마이징
- **카메라 색상**: 화이트, 파스텔톤(미스티로즈, 라벤더, 스카이블루, 민트, 크림), 차콜 (7가지)
- **배경 설정**: 배경 색상과 그라데이션 강도 조절
- **실시간 미리보기**: 변경사항 즉시 확인

### 💾 저장 옵션
- **PNG 저장**: 고화질(6배 스케일) 정적 이미지
- **GIF 저장**: 애니메이션 옵션
  - 정적 GIF (반복)
  - 슬라이드 애니메이션 (사진이 오른쪽으로 출력)

### ✨ 기술 특징
- **반응형 디자인**: 모든 기기에서 동일한 사이즈 저장 (1280×1600)
- **고화질 렌더링**: 6배 스케일로 고화질 이미지 생성
- **오프라인 지원**: 인터넷 없이 저장 기능 작동
- **실시간 렌더링**: 모든 변경사항이 실시간으로 미리보기에 반영

## 파일 구조

```
polar/
├── index.html      # 메인 HTML
├── style.css       # 스타일시트 (연한 모노톤 + 파스텔톤 테마)
├── script.js       # 메인 JavaScript (캔버스 렌더링, 이벤트 처리)
├── gif.js          # GIF 라이브러리
├── gif.worker.js   # GIF 워커 스크립트
└── README.md       # 문서
```

## 사용 방법

1. 사이트 접속
2. 카메라 색상 선택
3. 사진 업로드
4. 사진 위치, 크기, 배경 설정 조절
5. PNG 또는 GIF로 저장

## 기술 스택

- **HTML5**: 문서 구조
- **CSS3**: 모던 디자인 (그라데이션, 백드롭 필터 등)
- **Canvas API**: 고화질 이미지 렌더링
- **Web Workers**: GIF 인코딩 병렬 처리
- **Blob API**: 파일 다운로드

## 성능 최적화

- 미리보기는 1배 스케일로 빠른 렌더링
- 저장 시에만 6배 스케일로 고화질 생성
- GIF 생성 시 워커 스레드 활용으로 UI 블로킹 방지
