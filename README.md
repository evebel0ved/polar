# Sofort Instant Camera

전문가 수준의 Sofort 인스턴트 카메라 시뮬레이터입니다.

## 특징

- **고급 Canvas 2D 렌더링**: 포토샵 품질의 카메라 그래픽
- **반응형 디자인**: 모든 화면 크기에 최적화
- **실시간 미리보기**: 즉시 반영되는 설정 변경
- **고화질 내보내기**: 6배 스케일 PNG, GIF 애니메이션
- **전문 UI/UX**: 10년차 디자이너 수준의 인터페이스

## 기능

- 6가지 카메라 색상 선택
- 사진 위치 및 크기 조절
- 3가지 배경 모드
- 슬라이드 애니메이션 (GIF)
- PNG, GIF 고품질 내보내기

## 기술 스택

- HTML5
- CSS3 (Grid, Gradient, Backdrop Filter)
- Vanilla JavaScript (Canvas 2D API)
- gif.js
